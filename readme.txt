PLANTED BY FAITH GARDEN SERVICE — WEBSITE FILES

Included:
- index.html: your website homepage
- assets/garden-hero.png: generated visual concept image

Preview:
Open index.html in a web browser. Keep the assets folder beside index.html.

Free publishing:
1. Use a free static website host such as Netlify (manual deploy) or GitHub Pages.
2. Upload the website files, keeping the assets folder and index.html together.
3. Your host will provide a public website address.
4. You can connect a custom domain later if you buy one.

Before publishing:
- Check that the WhatsApp number is correct.
- Replace the gallery placeholders with real photos of your work when you have them.
- Add the specific towns/suburbs you serve if you want customers to know your service area.
